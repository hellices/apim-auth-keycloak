Project: Keycloak Authentication with Azure APIM for AI Foundry Models
======================================================================

OVERVIEW
--------
This project provides a complete infrastructure and configuration setup for:
1. Keycloak identity provider running on Azure Kubernetes Service (AKS)
2. Azure API Management (APIM) as an API gateway
3. Azure OpenAI (AI Foundry) service integration
4. JWT-based authentication flow from Keycloak to APIM to Azure OpenAI

ARCHITECTURE
------------
User → Keycloak (AKS) → JWT Token → APIM (Validation) → Azure OpenAI

Components:
1. Keycloak: Identity provider with OIDC/OAuth2
2. PostgreSQL: Keycloak database
3. AKS: Kubernetes cluster hosting Keycloak
4. ACR: Container registry
5. APIM: API gateway with JWT validation
6. Azure OpenAI: GPT-4 model deployment

Security:
- JWT signature validation
- Token issuer verification
- Audience validation
- Rate limiting per user
- API key management in APIM
- Secrets stored securely

DEPLOYMENT STEPS
----------------
1. Deploy infrastructure: azd up (~10 minutes)
2. Deploy Keycloak: kubectl apply -f kubernetes/keycloak-deployment.yaml (~5 minutes)
3. Configure Keycloak: Create realm, client, user (~10 minutes)
4. Configure APIM: Update named values, import API, apply policies (~5 minutes)
5. Test: Get token and call API (~2 minutes)

Total setup time: ~30 minutes
